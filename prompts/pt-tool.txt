너는 시니어 웹 개발자야. 지금 연결된 GitHub 저장소에 「강의용 발표(PT) 도구」를 처음부터 끝까지 만들어 줘.
중간에 나에게 묻지 말고, 아래 [완료 기준]을 모두 통과할 때까지 스스로 만들고 → 브라우저로 확인하고 → 고쳐.

[목표]
코드를 모르는 강사가 브라우저만으로 교안(슬라이드)을 만들고, 고치고, 발표하는 도구.

[기술 조건]
- 빌드 도구·프레임워크 없이 HTML · CSS · 순수 JavaScript 파일만 쓴다.
- 슬라이드 한 장은 1920×1080 좌표를 쓰고, 화면 크기가 달라도 비율을 지켜 줄어든다.
- 교안 하나 = JSON 하나. 브라우저(localStorage)에 자동 저장하고, JSON 내보내기 · 불러오기를 둔다.
- 화면 글은 모두 쉬운 한국어. 글꼴은 Pretendard(CDN).

[화면 3개]
1. 목록(index.html): 교안 카드, 새 교안, 복제, 이름 바꾸기, 삭제(확인창), [발표] 바로 시작.
2. 편집기(editor.html): 왼쪽 슬라이드 썸네일(끌어서 순서 바꾸기), 가운데 슬라이드, 오른쪽 속성 패널.
   - 넣을 수 있는 것: 제목 · 본문 글 상자, 도형(사각형 · 원 · 화살표), 이미지(붙여넣기 · 끌어 놓기), 표.
   - 끌어서 옮기기, 모서리로 크기 조절, 가운데 · 가장자리 정렬 안내선.
   - Ctrl+Z / Ctrl+Y, Ctrl+C / Ctrl+V, Delete, 방향키로 조금씩 옮기기.
   - 슬라이드 모양 5가지(표지 · 제목+본문 · 두 단 · 큰 숫자 · 구역 제목), 테마 4가지(밝은 · 어두운 · 소방 주황 · 칠판).
   - 요소마다 "몇 번째 클릭에 나타날지" 정하기.
   - 슬라이드마다 발표자 노트 칸.
3. 발표(present.html): 전체화면 발표.
   - PowerPoint 와 같은 키: → · Space · PageDown 다음, ← · PageUp 이전, 번호+Enter 이동, B 검은 화면, W 흰 화면, Esc 끝내기. 발표용 리모컨이 그대로 동작해야 한다.
   - 휴대폰: 좌우로 밀어서 넘기기.
   - S 키: 발표자 보기 창(지금 · 다음 슬라이드, 노트, 지난 시간). 두 창은 BroadcastChannel 로 함께 넘어간다.

[샘플]

[배포]

- 모든 변경을 커밋하고 GitHub 에 푸시한다.

[완료 기준 — 직접 확인하고 보고]
- 세 화면이 콘솔 오류 없이 열린다.
- 새 교안 → 슬라이드 3장 → 글 · 도형 · 이미지 넣기 → 새로 고침해도 그대로 있다.
- 발표 화면에서 다음 · 이전 · B · 번호 이동이 된다.
- 휴대폰 폭(390px)에서 가로 스크롤 없이 발표된다.
