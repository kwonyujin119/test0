1-1

PT 툴 복사해 오기

빈 저장소 my-pt(Public)를 만들고, Claude Code에서 그 저장소를 고른 뒤 첫 메시지로

이 저장소에 PT 툴을 복사해 넣어 줘. 코딩은 네가 하고, 내가 눌러야 하는 것만 화면 순서대로 짧게 알려 줘.

1) 아래 공개 저장소에서 pt-tool 폴더 안의 파일만 가져와 이 저장소 맨 위에 그대로 넣을 것. 다른 폴더는 가져오지 말 것
   git clone --depth 1 --filter=blob:none --sparse https://github.com/kwonyujin119/test0.git /tmp/src
   cd /tmp/src && git sparse-checkout set pt-tool
   그다음 /tmp/src/pt-tool/ 안의 것(숨은 폴더 .github 포함)을 이 저장소 맨 위로 복사
2) 커밋하고 기본 브랜치(main)에 올릴 것
3) GitHub Pages 켜기: 내가 저장소 Settings → Pages → Source 를 「GitHub Actions」로 고르게 안내
4) 배포가 끝나면 주소 확인: https://(내 아이디).github.io/my-pt/gyoan.html

[끝나면 보고]
- 교안 목록 · 편집기 · 발표 화면을 열어 본 캡처 (예시 교안이 보여야 함)
- 웹에서 바로 저장하고 싶을 때 [GitHub 연결] 에 넣을 토큰 만드는 법 (권한: 이 저장소 Contents 읽기/쓰기만)
2-1

내 것으로 다듬기

툴이 열린 뒤, 바꿀 것만 골라서

이 PT 툴을 내 것으로 다듬어 줘. 앱 기능은 그대로 두고 아래만 바꿀 것.
- 목록 화면 이름: (예: 안전교육 교안함)
- 예시 교안 표지의 기관명 · 강사 이름: (예: ○○소방서 · 홍길동) — 로고 그림은 내가 올린 파일로
- 강조색: (예: #C62828), 글꼴은 그대로
- 추가로 필요한 것: (예: 발표 화면 오른쪽 아래에 우리 기관 로고 작게)
app/ 파일을 고쳤으면 sw.js 의 CACHE 숫자를 하나 올릴 것.
[끝나면 보고] 바뀐 화면 캡처, 바꾼 파일 목록
3-1

1. 초안 만들기

주제만 바꿔서

새 교안 초안을 만들어 줘. 예시 교안 「예시 · Let's Make PT Together」와 같은 형식 · 같은 디자인(바탕 · 글꼴 · 카드 · 장 표지)으로.
- 주제: (예: 소화기 사용법) · 대상: (예: 신입 직원) · 시간: (예: 20분) · 10장 안팎
- 표지 → 목차 → 본문 → 정리. 한 장에 메시지 하나, 제목은 결론 문장으로
- 설명은 발표자 노트에, 화면 글은 짧게. 숫자는 크게 하나만
- 끝나면 교안 목록에 보이게 하고, 발표 주소를 알려 줘
3-2

2. 점검시키기

초안이 나온 뒤

방금 만든 교안의 모든 장을 화면으로 캡처해서 직접 점검해 줘.
- 글 넘침 · 겹침 · 잘림, 24px보다 작은 글자, 바탕과 글자 대비
- 한 장에 메시지가 둘 이상인 장, 글이 너무 많은 장
문제는 표로 보여 주고, 고친 뒤 다시 캡처해서 0개가 될 때까지 반복해 줘.

3. 피드백 주기

고치고 싶은 곳을 장 번호와 함께

교안을 이렇게 고쳐 줘.
- (3)장: (제목을 더 짧게)
- (5)장: (카드를 클릭할 때마다 하나씩)
- (전체): (강조색을 파랑 하나로)
고친 장만 캡처해서 보여 줘.

5-1

퀄리티 한 번에 올리기

교안 초안이 나온 뒤

교안 「(교안 이름)」에 효과를 걸어 줘. 효과는 이 툴에 이미 있는 것만 쓰고, 새로 만들거나 앱 코드를 고치지 말 것.
예시 교안 「예시 · Let's Make PT Together」를 먼저 열어 어떻게 쓰였는지 보고 같은 방식으로.

1. 모든 장: 장이 열리면 자동으로(enter) 위에서 아래로 0.1초 간격 — 제목 words, 카드 up, 번호 pop, 사진 zoom, 선 wipe
2. 장 표지: 배경 사진 kenburns(22초), 큰 번호 focus, 시작 막 out(발표 화면 전용 po), 제목 반짝임 sheen
3. 클릭 단계(step): 카드 · 항목이 클릭마다 하나씩, 같은 클릭 안에서는 위쪽부터 0.1초씩 늦게
4. 큰 숫자: count (0 → 값), 시간이 핵심인 숫자 하나는 강조 countdown(실제 초)
5. 가장 중요한 칸 하나만 glow
6. 사진 위 글: 글 쪽을 어둡게 덮는 그라데이션 도형(fill2)으로 읽히게
7. 장 넘김: 장 표지는 blur, 나머지는 fade

[지킬 것] 글 · 내용 · 배치는 바꾸지 말 것. 장마다 효과 2~4가지 이내.
[끝나면 보고] 발표 화면을 장마다 열어 3초 뒤 캡처, 글 넘침 0개 확인.
