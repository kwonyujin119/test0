한 번에 만들기

Claude Code에서 my-pt 저장소를 고르고 첫 메시지로

너는 웹 개발자야. 나는 코딩을 모르는 강사야.
지금 연결된 저장소에 브라우저에서 쓰는 나만의 발표 프로그램(PT 툴)을 처음부터 끝까지 만들어 줘.
아래 순서대로 네가 알아서 진행하고, 단계마다 직접 확인한 뒤 다음으로 넘어가. 내가 직접 눌러야 하는 것만 화면 순서대로 짧게 알려 줘.

1) 교안 형식
- 교안 1개 = JSON 파일 1개 (decks/ 폴더). 슬라이드 1920×1080 좌표
- 요소: 글 · 그림 · 도형. 각 요소에 step(몇 번째 클릭에 나타날지)
- 형식 설명은 docs/format.md 에 한국어로

2) 발표 화면 present.html  (발표기)
- → · Space · 클릭: 다음 / ← 이전 / 숫자+Enter 이동
- F5 전체 화면 · B 검은 화면 · S 발표자 보기(다음 장 · 노트 · 시간)
- 16:9 비율 유지, 휴대폰은 밀어서 넘기기
- 참고: reveal.js 와 PowerPoint 쇼의 조작 방식 (라이브러리는 쓰지 말 것)

3) 교안 목록 index.html (첫 화면)
- 교안을 카드로: 첫 장 미리보기 · 제목 · 장 수. 누르면 발표
- 검색칸. 휴대폰 1열 · PC 3~4열

3-1) 편집 화면 editor.html  (편집기)
- 교안 목록 카드의 [편집]으로 열기. 왼쪽 장 목록 · 가운데 슬라이드 · 오른쪽 속성
- 글 더블클릭해 고치기, 끌어서 옮기기 · 크기 바꾸기, 장 추가 · 복제 · 삭제 · 순서 끌기
- 고친 내용은 이 기기에 자동 저장, [JSON 내려받기] 로 파일 받기 (받은 파일을 이 대화창에 올리면 저장소에 반영)

4) 예시 교안 하나
- 주제: (내 강의 주제) · 대상: (예: 신입 직원) · 10장 안팎
- 표지 → 목차 → 본문 → 정리. 한 장에 한 메시지, 글자 24px 이상, 설명은 발표자 노트에

5) 인터넷에 공개
- GitHub Pages 로 공개. 내가 눌러야 하는 설정이 있으면 순서대로 알려 줘

6) 작업 규칙 문서 CLAUDE.md
- 고치기 전에 최신 상태 받기 · 한 번에 한 가지만 · 고친 뒤 화면으로 확인 · 비밀 자료와 토큰은 절대 올리지 않기

[하지 말 것]
- npm · React 같은 빌드 도구 금지. HTML · CSS · JS 파일만
- 비밀번호 · 토큰을 대화창에 붙여넣으라고 하지 말 것

[끝나면 보고]
- 사이트 주소와 예시 교안 발표 주소
- 단축키를 하나씩 시험한 결과 표
- PC · 휴대폰 화면 캡처

레퍼런스 모아 고치기

툴 초안이 나온 뒤

내가 만든 PT 툴을 업그레이드해 줘. 순서대로 진행하고 단계마다 화면으로 직접 확인해.

1) 레퍼런스 조사: PowerPoint · Keynote · Google Slides · reveal.js · Pitch 의 발표 · 편집 · 목록 화면에서 좋은 점을 기능별로 표로 정리
2) 우리 툴과 비교: 표에 '우리 툴 있음 / 없음 / 부족' 칸을 붙이고, 효과 큰 순서로 10가지 고를 것
3) 디자인 기준(이대로 고정)
- 글꼴: Pretendard(없으면 맑은 고딕), 제목 56~72px · 본문 28~36px, 24px 미만 금지
- 색: 바탕 #FAFAF7, 글자 #15181C, 강조 #2457D6 하나만, 경고 #B3261E
- 여백: 슬라이드 가장자리 96px, 카드 모서리 24px
4) 10가지를 하나씩 고치고, 하나 끝날 때마다 PC · 휴대폰 화면 캡처로 확인

5-1

전부 한 번에

PT 툴과 교안이 나온 뒤

내가 만든 PT 툴에 아래 효과들을 하나씩 추가해 줘. 하나 끝날 때마다 예시 교안에서 직접 확인하고, 다음으로 넘어가. 라이브러리는 쓰지 말고 HTML · CSS · JS만.

1. 모든 장 등장 모션
장이 열리면 요소가 위에서 아래로 0.1초 간격으로 차례로 나타나게 해 줘. 제목은 아래에서 떠오르게, 사진은 살짝 커지며 나타나게. 미리보기 · 인쇄 화면에는 효과 없이 완성된 모습으로 보이게.

2. 클릭할 때마다 하나씩
발표 중 클릭(→ · Space)할 때마다 카드 · 항목이 하나씩 나타나게 해 줘. 뒤로 가면 움직임 없이 사라지게. 편집기에서 요소마다 '몇 번째 클릭'을 고를 수 있게.

3. 장 표지를 영화처럼
장 표지에 들어가면 검은 막이 1초 동안 걷히고, 배경 사진이 20초 동안 아주 천천히 확대되게 해 줘. 큰 번호는 흐릿하다가 선명해지게.

4. 제목 단어씩 떠오르기
제목 글자를 단어 단위로 나눠 0.1초 간격으로 흐림에서 선명해지며 떠오르게 해 줘.

5. 숫자 0부터 올라가기
큰 숫자(예: 1,250명, 300만원)는 장이 열리면 0부터 그 값까지 1.5초 동안 올라가게 해 줘. 쉼표와 단위는 그대로.

6. 실제 시간 카운트다운
숫자 하나를 클릭하면 실제 초 단위로 0까지 줄어들게 해 줘(예: 42초). 줄어드는 동안 화면이 점점 어두워지고, 0이 되면 1.5초 뒤 다음 장으로 넘어가게.

7. 강조: 빛나기 · 한 곳만 색
강조하고 싶은 칸은 은은하게 한 번 빛나게 하고, 사진은 흑백으로 바꾼 뒤 중요한 부분만 색이 남게 하는 효과를 추가해 줘.

8. 사진 위 글자 읽히게
배경 사진 위에 글이 있으면 글 쪽을 어둡게(또는 밝게) 덮는 그라데이션을 깔아 글이 어디서나 읽히게 해 줘.

9. 스포트라이트 · 돋보기
사진에서 한 곳만 밝게 남기고 주변을 어둡게 하는 스포트라이트, 한 부분을 동그랗게 확대하는 돋보기 효과를 클릭 단계로 쓸 수 있게 해 줘.

10. 진행 표시
발표 화면 위쪽에 얇은 진행 막대와 '지금 몇 번째 파트' 표시를 넣어 줘. 장 표지에는 전체 파트 중 현재 파트만 진하게.

11. 장 넘김 효과
장 전환을 장마다 고를 수 있게 해 줘: 서서히 · 흐림 · 밀어내기 · 확대. 기본은 서서히(0.5초).

12. 편하게 보는 설정
컴퓨터의 '움직임 줄이기' 설정을 켠 사람에게는 큰 움직임 대신 서서히 나타나기만 쓰게 해 줘. 글자는 24px 이상, 배경과 글자 대비는 4.5:1 이상 유지.
