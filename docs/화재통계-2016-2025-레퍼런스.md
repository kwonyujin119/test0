# 최근 10년 화재 통계(2016–2025) 레퍼런스

교안 `decks/최근 10년 화재 통계 2016-2025.json` 을 만들 때 모은 자료입니다.
소방청 · 국가화재정보시스템 · 공공데이터포털 · 국가지표체계 사이트는 작업 환경에서 직접 열리지 않아, 소방청 발표를 인용한 보도와 통계연보 요약 기사로 숫자를 모았습니다. **발표 전에 nfds.go.kr 에서 한 번 더 맞춰 보십시오.**

같은 해라도 첫 발표값과 통계연보 확정치가 다릅니다. 교안에서는 확정치(있으면)를 쓰고, 다른 값은 발표자 노트에 남겼습니다.
2025년 3~5월 대형 산불 사망자(보도 32명)는 산림청 집계라 위 통계에 포함되는지 확인이 필요합니다.
