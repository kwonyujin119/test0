# 소방안전교육 및 훈련 — 교안 근거와 구성 (초안)

- 근거: 소방안전관리자 2급 교재 제8편 제1장 소방안전교육 및 훈련(p.373~381, 사용자 제공 PDF 9쪽). 교재 학습정리 · 학습평가에는 「제6편」으로 적혀 있으나 본문 쪽 표시는 「제8편」 — 교안은 제8편으로 표기.
- 19장: 표지 · 강사 소개 · 오늘의 지도 / 1단계 개념 · 원칙(정의 · 원칙 7 · 동기부여 10 · 나머지 4 · 퀴즈) / 2단계 계획(시기 · 연간 예시 · 세부계획 서식 · 시나리오) / 3단계 준비 · 실시(교안 50분 시간 막대 · 실시 5가지) / 4단계 평가 · 기록(설문 · 강평 · 기록부 2종 · 퀴즈) / 한 장 정리.
- 교재 표(연간 계획서 · 교안 예시 · 설문지)는 도형으로 다시 그림. 교재 스캔 사용 안 함.
- 강사 작성 부분(교재 아님): 원칙 외우는 법 「학 · 동 · 목 · 현 · 실 · 경 · 관」, 6장 「10초 안에」 예시, 8장 「예)」 중 ④ · ⑥, 7장 윗줄 · 아랫줄 구분, 16장 「8번이 핵심」 해석.
- 강의 구성 자체가 7원칙을 따르도록 함(한 번에 하나 · 실습 연결 · 퀴즈 · 마지막 설문).

## 2판 (1시간 · 문제풀이 · 다중 에이전트 검토)

- 구성: 강의 35분 + 문제풀이 15분(8문항) + 정리 10분. 26장. 강의 장마다 ⏱ 시간 표시.
- 문항: 교재 학습평가 2문항 + 교재 본문으로 새로 쓴 6문항(공식 기출 아님). 정답 위치 고르게, 함정 한 줄.
- 내용 수정: 「안전의식을 고치고」 → 「고취하고」, 설문 문구 교재대로, 「설문 = 가장 용이하고 정확한 방법 중 하나」, 이론 종류 「세미나/워크숍」, 「강의 25분 + 실습 25분」.
- 표지 오른쪽 사진은 임시(사용자 제공 사진 파일 대기).
