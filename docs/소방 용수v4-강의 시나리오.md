### 3. 지휘차에 오른 첫 5분 (1.5분)

  - 3번이 적었다면 덧붙입니다: "3번이 적었다면, 그게 오늘 이 강의가 필요한 이유입니다."

## 흐름 검토 — 바꾸면 좋은 곳 (교안은 아직 그대로)

1. **Ⅴ부가 너무 깁니다 (50분, 전체의 43%).** 결론이 105분 지점에 와서, 청중이 지친 상태에서 마무리하게 됩니다.
   - Ⅳ 끝(38장)에서 휴식을 넣고, Ⅴ부는 실습 위주로 운영하는 것을 권장합니다.
2. **원창동 데이터 두 장(36 · 37)이 Ⅳ부에 있는데, 읽는 법은 Ⅴ부(49 · 52)에서 가르칩니다.**
   - 권장: 36 · 37을 Ⅴ부 유량 데이터로 옮겨 **49 그래프 읽기 → 37 원창동 → 50 석남 → 51 적산 → 36 블록별 11배 → 52 네 단계** 순서로 둡니다.
   - 그러면 Ⅳ부는 개념, Ⅴ부는 확인으로 깔끔하게 나뉩니다.
3. **Ⅰ부는 '전국 → 인천' 순서가 자연스럽습니다.**
   - 지금은 전국(8–10) → 인천(11–13) → 다시 전국(14)입니다.
   - 권장: 14장을 10장 바로 뒤로 옮겨 **전국 통계 → 전국 대형 화재 → 인천 사진 → 원창동 영상 → 인천 2단계 → 소방력 3요소**로 좁혀 들어갑니다.
