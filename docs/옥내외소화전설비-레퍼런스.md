# 옥내외소화전설비 교안 — 근거 · 설계 레퍼런스

교안: `decks/옥내외소화전설비.json` (22장 · 2시간)
- 1교시 0~60분: 1~13장
- 13장 끝에서 끊고 휴식(쉬는 시간은 2시간에 포함하지 않음)
- 2교시 60~120분: 14~21장
- 장마다 오른쪽 위에 「교시 · 분」을 표시하고, 발표자 노트에도 [시:분] 구간을 적었습니다.

## 내용 근거
- 사용자 제공 PDF: 한국소방안전원 「2급 소방안전관리자」 교재 제5편 제2장 소화설비
  - 제3절 옥내소화전설비(152~169쪽)
  - 제4절 옥외소화전설비(170~171쪽)
- 교재 안에서 인용된 기준: 옥내소화전설비의 화재안전기술기준(NFTC 102), 공동주택(NFTC 608), 창고시설(NFTC 609)
- 계산 예시(수원, 방수량 Q = 2.065D²√p)는 교재 공식으로 발표자가 계산했습니다(예: p = 0.17 MPa → 143.9 L/min, p = 0.13 MPa → 125.8 L/min).
- 저작권: 교재 사진 · 그림은 넣지 않았습니다. 계통도 · 릴리프밸브 · 성능시험배관 · 소화전함 · 피토게이지 그림은 도형으로 새로 그렸습니다.

## PT 기법 · 디자인 근거와 적용

| 기법 | 근거 | 적용 |
|---|---|---|
| 주장-근거형 제목(결론 문장) | Garner & Alley(2013, Int. J. Engineering Education 29(6)) — 공학 수강생 이해 · 기억 향상. 반론: Farkas(2010) | 모든 장의 제목이 한 문장 결론 |
| 신호(signaling) | Mayer 멀티미디어 학습 원칙 | 위쪽 「수원 → 가압송수 → 배관 → 기동장치 → 소화전함 → 제어반」 흐름 막대에서 현재 부분 강조 |
| 분절(segmenting) · 사전학습(pre-training) | Mayer | 클릭마다 한 단계씩 나타남 · 3장에서 숫자 8개 먼저 제시 |
| 공간 근접(spatial contiguity) | Mayer | 그림 바로 옆에 이름표 · 설명 |
| 색 의미 고정 | 데이터 시각화 원칙(앞선 교안 레퍼런스) | 물 · 옥외 = 파랑, 불 · 옥내 · 경고 = 빨강, 정답 = 초록, 주의 = 주황 |
| 풀이 예제(worked example) | 인지부하 이론 | 수원 계산 2개, 방수량 계산 합격/불합격 2개 |
| 회상 연습(retrieval) | 학습과학 | 13장 퀴즈 4문항, 21장 빈칸 복습 안내 |
| 진행 표시 · 시간 표시 | 목차 · 진행 표시 레퍼런스(Juice Analytics 등) | 교시 배지와 분 단위 시간 |
