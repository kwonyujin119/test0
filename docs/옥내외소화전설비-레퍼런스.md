# 옥내외소화전설비 교안 — 근거 · 설계 레퍼런스

교안: `decks/옥내외소화전설비.json` (22장 · 2시간)
- 1교시 0~60분: 1~13장
- 13장 끝에서 끊고 휴식(쉬는 시간은 2시간에 포함하지 않음)
- 2교시 60~120분: 14~21장
- 장마다 오른쪽 위에 「교시 · 분」을 표시하고, 발표자 노트에도 [시:분] 구간을 적었습니다.

## 내용 근거
- 사용자 제공 PDF: 한국소방안전원 「2급 소방안전관리자」 교재 제5편 제2장 소화설비
  - 제3절 옥내소화전설비(152~169쪽)
  - 제4절 옥외소화전설비(170~171쪽)
- 교재 안에서 인용된 기준: 옥내소화전설비의 화재안전기술기준(NFTC 102), 공동주택(NFTC 608), 창고시설(NFTC 609)
- 계산 예시(수원, 방수량 Q = 2.065D²√p)는 교재 공식으로 발표자가 계산했습니다(예: p = 0.17 MPa → 143.9 L/min, p = 0.13 MPa → 125.8 L/min).
- 저작권: 교재 사진 · 그림은 넣지 않았습니다. 계통도 · 릴리프밸브 · 성능시험배관 · 소화전함 · 피토게이지 그림은 도형으로 새로 그렸습니다.

## 4판 (균형 · 가독성 · 표지)

적용한 가독성 기준(실무 지침 · 연구에서 가져온 경험칙 — 실험으로 정해진 고정값은 아님)

- 줄간격 1.45~1.6 — 1.5 권장(WSU · UF IFAS 발표 지침).
- 한 줄 길이: 한글 웹 문서 실험(대한산업공학회, 2003)에서 50자 글줄 · 100% 줄간격이 읽기 속도에 유리 → 슬라이드는 더 먼 거리에서 보므로 한 줄 약 40자 이하로 유지.
- 카드 계층: 라벨 30px 굵게(색) → 본문 28~32px(검정). 내용보다 지나치게 큰 상자는 줄여 빈 공간을 줄임.
- 한글은 단어 중간에서 줄이 바뀌지 않게(word-break: keep-all — 렌더러 기본값 확인).

- 15장: 「사진 속 틀린 점은?」 장치를 없애고 「① 직사형 관창 · ② 노즐 끝 D/2 · 직각」 배지로 바꿈.

- 2장에 강사 소개 추가(사용자 제공 초안 내용 그대로: 소속 · 학력 · 경력 4개 · 소방공무원 / 소방기술사).
- 스타일: 초안의 「“ 강사 소개」 · 남색 왼쪽 패널 구성을 살리되 교안 색 체계(남색 · 빨강 · 파랑)에 맞춤. 경력은 2장 시간표와 같은 형식의 가로 타임라인(현재 직위만 빨강).
- 초안 배경의 강연자 사진은 출처를 알 수 없어 쓰지 않음.

- 장 번호 참조를 모두 +1(1교시 1~14장, 2교시 15~23장, 14장 휴식).

## 7판 (내용 재검토 · 도식 교체)

내용 오류 수정
- 13장 창고시설(NFTC 609): 「압력스위치를 함 안에 둘 수 있는 단서」 → 「기동스위치를 함 안에 둘 수 있는 단서」(NFTC 102의 학교 · 공장 · 창고 동결 우려 장소 단서). 상시 근무 · 동결 우려 없는 물류창고 등은 이 단서를 쓰지 않음.
- 17장 펌프성능시험 도식: 펌프 → ① → ② → F → ③을 한 줄로 이어 그려 ①을 닫으면 시험배관도 막히는 것처럼 보였음 → 성능시험배관이 펌프와 ① 사이에서 갈라지도록 다시 그림.
- 10장: 「성능시험배관은 펌프와 토출측 개폐밸브 사이에서 분기」 문구 추가.
- 19장 표시등: 「켜져 있으면 고장 · 물 없음」 → 「압력 저하 · 물 부족, 원인 확인」(압력스위치 표시등은 고장 표시가 아님).

이미지
- 12장 소화전함: 사용요령 그림 순서가 문 → 호스 → 밸브 → 방수로 바뀐 이미지로 교체(해상도 518×645로 이전보다 낮음).
- 5장 ④ 방수: 호스를 옆구리에 붙인 자세로 교체.
- 16장 피토게이지: 생성 이미지 대신 도형 도식(관창 · 물줄기 · 게이지 날 · D/2 · 직각)으로 교체. 게이지 제품 사진은 받으면 추가.

확인하지 못한 것
- 13장 공동주택(NFTC 608) 감시제어반 전용실 위치의 조건부 예외(지상 2층 · 지하 2층)는 NFTC 608 원문과 대조하지 못함.
