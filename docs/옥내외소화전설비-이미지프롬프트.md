# 옥내외소화전설비 교안 — 이미지 생성 프롬프트 (ChatGPT용)

## 공통 원칙(모든 프롬프트 끝에 이미 포함)
- 사진처럼 사실적인 스타일 · 한국의 실내 · 실외 환경
- 이미지 안에 글자 · 숫자 · 로고 · 워터마크를 넣지 않음. 교안에서 글을 따로 얹음.
- 색감: 남색(#0B1628) · 소방 빨강(#C81E1E) · 물 파랑(#1D4ED8)과 어울리는 차분한 톤
- 비율은 장마다 지정. 교안의 기존 글과 겹치지 않도록 「비워 둘 자리」를 적어 둠.

## 생성 이미지를 쓰지 않는 장
- 5장 계통도 · 9장 배관 · 10장 압력챔버 · 16장 펌프성능시험 · 17장 성능곡선
- 이유: 밸브 위치 · 배관 연결 · 장치 구조를 틀리게 그릴 위험이 큼. 도형 그림 유지.

## 넣는 방법
1. ChatGPT에서 이미지를 만든 뒤 PNG로 저장합니다.
2. 편집기에서 그 장을 열고 이미지를 끌어다 놓습니다.
3. 위에 적은 위치 · 크기로 맞춥니다.
4. 글과 겹치면 이미지를 「맨 뒤로」 보내고 투명도를 낮춥니다.

이미지에 글자가 생기면 같은 프롬프트로 다시 만들거나, 「글자를 모두 지워 줘」라고 한 번 더 지시하십시오.
