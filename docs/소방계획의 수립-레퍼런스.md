# 소방계획의 수립 — 교안 근거와 구성 (초안)

- 근거: 소방안전관리자 2급 교재 제6편 제1장 소방계획의 수립 · 제2장 자위소방대 및 초기대응체계 구성 · 운영 · 제3장 화재대응 및 피난(p.249~269, 사용자 제공 PDF 1~21쪽).
- 교재 그림(수립절차 · TYPE 구성도 · 구역 설정 예시)은 모두 도형으로 다시 그림. 교재 스캔 · 삽화는 쓰지 않음.
- 31장: 표지 · 강사 소개 · 오늘의 지도 / 1장(장 표지 + 8장 + 퀴즈) / 2장(장 표지 + 8장 + 퀴즈) / 3장(장 표지 + 5장 + 퀴즈) / 한 장 정리.
- 색 의미: 1장 파랑 · 2장 초록 · 3장 빨강(화재대응). 상단 세 칸 막대 = 지금 몇 장인지(신호 주기).
- 기법: 결론형 제목(assertion-evidence), 클릭마다 하나씩(분할), 장마다 확인 퀴즈(인출 연습), 마지막 한 장 정리.
- 다시 배열한 곳: 소방계획서 주요내용 15가지를 네 묶음(현황 2 · 예방 · 점검 · 관리 7 · 조직 · 훈련 2 · 대응 · 피난 4)으로 묶음 — 교재 순서와 다름.
- 주의: 훈련 달력(기본 3 · 9월, 피난 4 · 10월, 종합 10월, 합동 11월)은 교재가 「참고할 수 있다」고 든 예시이며 법정 시기가 아님.
- 강사 소개 아래 한 줄 문장은 초안 — 강사가 고쳐 쓸 것.

## 2판 (3시간 · 문제풀이 · 다중 에이전트 검토)

- 구성: (강의 35분 + 문제풀이 15분 + 휴식 10분) × 3, 마지막 10분 정리 · 질문. 58장. 강의 장마다 ⏱ 시간 표시.
- 문제풀이 3블록 × 8문항: 기존 문제은행(교재 기반) + 교재 본문으로 새로 쓴 문항. 공식 기출 아님. 정답 위치 ①~④ 각 2번, 문항마다 「함정」 한 줄.
- 추가: 피난계획 수립 예시 그림 장(sp27b), 장 표지 질문(훅) · 장 연결 문장, 강의 중 30초 인출 질문 3회, 짝 활동 1회, 함정 부제.
- 검토 체계: PT 기법 · 디자인 · 내용 편집 에이전트 병렬 검토 → 팀장(이 세션) 반영 → 감사 에이전트(PDF 30곳 대조, 84장 확인) → 지적 16건 수정.
- 내용 수정: 나수인 → 다수인 피난장비(+비상구), 초기대응체계 점선 연결 대상, 노약자 유도자 문구, 지체장애 보조 문구, 「화세 보고」 → 「화세 확대 여부를 고려해」, 작성원칙 제목(교재: 핵심 = 위험관리), 책임과 권한 문구, 「가급적」 편안한 자세.
- 표지 오른쪽 사진은 임시(사용자 제공 사진 파일 대기).
