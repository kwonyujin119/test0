## 앱으로 설치해서 쓰기

브라우저 탭이 아니라 **전용 앱 창**으로 씁니다 (크롬 또는 엣지).

1. 크롬·엣지에서 https://kwonyujin119.github.io/test0/ 를 엽니다.
2. 첫 화면의 **⬇ 앱으로 설치** 단추(또는 주소창 오른쪽 설치 아이콘 ⊕)를 누릅니다.
3. 바탕화면·시작 메뉴·작업 표시줄에 **업무 공간** 아이콘이 생깁니다. 이후로는 이 아이콘으로 엽니다.

- 작업 표시줄 아이콘을 오른쪽 클릭하면 **한글 작업장 / 교안 작업장** 으로 바로 들어갈 수 있습니다.
- 앱으로 설치하면 탐색기에서 `.hwpx` 파일을 **연결 프로그램 → 업무 공간** 으로 열 수 있고, 저장(Alt+S)하면 그 파일에 바로 저장됩니다.
- 인터넷이 될 때는 늘 최신 버전으로 열리고, 끊겼을 때는 마지막으로 받아 둔 화면으로 열립니다 (문서함·GitHub 저장은 인터넷 필요).
- 집 PC 와 사무실 PC 에 각각 한 번씩 설치하면 됩니다.

## 한글 작업장

사무실 한글에서 만든 문서를 집에서(한글이 없어도) 이어서 고치고, 다시 사무실 한글에서 여는 용도입니다.

- **열기**: `.hwpx` 파일을 열거나 화면에 끌어다 놓습니다. `.hwp`(옛 형식)는 한글에서 *다른 이름으로 저장 → 한글 표준 문서(*.hwpx)* 로 한 번 바꿔 주세요.
- **저장**: 크롬·엣지에서는 연 파일에 그대로 덮어씁니다(Alt+S). 다른 브라우저는 내려받기 폴더에 저장됩니다.
- **원본 보존**: 손대지 않은 문단·표·그림·필드·머리말은 원본 XML 을 그대로 다시 씁니다. 편집한 문단만 새로 만들어서, 한글에서 열었을 때 모양이 유지됩니다.
- **문서함 (🔒)**: 집·사무실 어디서나 같은 문서를 열 수 있게 GitHub 저장소 `hwp/` 폴더에 보관합니다.
  이 저장소는 공개라서 **문서는 브라우저 안에서 암호(AES-256)로 잠근 뒤** 올라갑니다. 파일 이름도 암호화된 목록에만 있습니다.
  암호를 잊으면 되살릴 수 없습니다. GitHub 연결(토큰)은 교안 작업장과 같습니다.
- **임시 저장**: 편집 중인 내용은 이 브라우저에 자동 보관되어, 창을 닫아도 시작 화면에서 이어서 열 수 있습니다.
- **할 수 있는 것**: 글자 모양(Alt+L) · 문단 모양(Alt+T) · 스타일(F6, Ctrl+1~9) · 개요 번호 · 글머리표 · 표(Ctrl+N,T, 셀 블록 F5, 합치기 M, 나누기 S, 줄/칸 추가·삭제, 배경·테두리, 너비 끌어 조절) · 그림 넣기·크기 조절 · 쪽 나누기 · 머리말/꼬리말 · 쪽 번호 · 편집 용지(F7) · 찾아 바꾸기 · 문자표 · 모양 복사(Alt+C) · 인쇄/PDF. 전체 단축키는 화면에서 **F1**.
- **그대로 보존만 하는 것**: 수식, 그리기 개체·글상자, 각주, 차트, 양식 개체 — 화면에 자리와 내용을 보여 주고 저장할 때 원본대로 둡니다 (편집은 한글에서).
- **글꼴**: 글꼴 칸 옆 **▾** 를 누르면 무료 글꼴 37종(고딕·명조·제목·손글씨·고정폭)을 그 모양 그대로 미리 보고 고를 수 있습니다. 이 글꼴들은 어느 PC 에서나 같은 모양으로 보입니다. 교안 작업장의 글꼴 목록도 같습니다.
- 한글 문서에 원래 있던 PC 글꼴(함초롬·HY 계열 등)은 그 PC 에 설치된 경우 그 모양으로 보입니다. 한글 전용 글꼴(함초롬·HY 계열)이 없으면 비슷한 글꼴로 보여 주므로 줄바꿈 위치가 조금 다를 수 있지만, 파일에는 원래 글꼴 이름이 그대로 저장됩니다.

# 교안 작업장

강의 교안을 **가볍게 만들고, 프레젠터 리모컨으로 발표**하는 도구입니다.
PowerPoint 처럼 텍스트·이미지·도형을 배치하지만, 설치 프로그램 없이 브라우저에서 동작하고
교안 하나가 JSON 파일 하나라서 Git 으로 모아 관리할 수 있습니다.

## 시작하기

1. `start.cmd` 를 더블클릭합니다. (PowerShell 로 로컬 서버가 뜨고 브라우저가 열립니다)
2. 브라우저에서 `http://localhost:8787/` 이 열리면 **＋ 새 교안** 으로 시작하거나,
   예시 교안을 **▶ 발표** / **✎ 편집** 해 봅니다.
3. 서버 창은 발표·편집하는 동안 켜 둡니다. 끝나면 창을 닫으면 됩니다.

> Windows 10 에 기본으로 있는 PowerShell 만 사용합니다. 별도 설치가 필요 없습니다.
> 포트를 바꾸려면 `powershell -ExecutionPolicy Bypass -File server.ps1 -Port 9000` 처럼 실행합니다.

## 어디서나 열기 (GitHub Pages)

`main` 브랜치에 푸시하면 GitHub Actions 가 자동으로 배포합니다 (`.github/workflows/pages.yml`).

**https://kwonyujin119.github.io/test0/**

- 토큰 없이 열면 **보기·발표** 만 됩니다. 강의실 PC 에서 주소만 열고 리모컨으로 발표하면 됩니다.
- 허브의 **GitHub 연결** 에 토큰을 한 번 등록하면 그 브라우저에서는 **편집·저장** 도 됩니다.
  저장할 때마다 저장소에 커밋이 하나씩 쌓이고(`교안 저장: …`, `이미지 추가: …`), 내 PC 에서는 `git pull` 로 받습니다.
- 토큰 만들기: [github.com/settings/personal-access-tokens/new](https://github.com/settings/personal-access-tokens/new) →
  Repository access: *Only select repositories* → `test0` → Permissions: **Contents → Read and write**.
  토큰은 브라우저(localStorage)에만 저장되고 GitHub 외에는 어디에도 보내지 않습니다. 공용 PC 에서는 발표만 하고, 연결하지 마세요.
- 이미지는 넣는 즉시 보이고 뒤에서 커밋됩니다. 연달아 넣으면 한 커밋으로 묶이고, 저장할 때 남은 이미지는 교안과 같은 커밋에 들어갑니다.
- 저장 직후 배포가 끝나기까지 30초~1분 걸립니다. 그 사이에도 교안은 GitHub API 로 바로 읽으므로 최신 내용이 보입니다.
  방금 올린 이미지는 배포 전이면 `raw.githubusercontent.com` 에서 대신 불러옵니다.
- 같은 교안을 PC(로컬 서버)와 웹에서 번갈아 편집할 때는, 로컬에서 작업하기 전에 `git pull`, 끝나면 `git push` 를 잊지 마세요.

- **이미지 꾸밈**: 자르기(확대·위치), 모양 틀(원·육각형·아치 …), 밝기·대비·채도·세피아·흐림, 흑백, 좌우 반전, 테두리·그림자.
  레이아웃의 빈 이미지 틀을 선택하고 붙여넣으면 그 틀에 그대로 들어갑니다.

  본문 목록은 `항목 하나씩 표시` 를 켜면 글머리 항목이 한 줄씩 나타납니다.
- **전환**: 페이드·밀어내기·위로 밀기·덮기·닦아내기·확대·흐리게 + **모핑** — 슬라이드를 복제(`Ctrl+Shift+D`)한 뒤 요소를 옮기거나 키우고
  전환을 "모핑"으로 두면, 발표 때 같은 요소가 부드럽게 이동·변형됩니다 (PowerPoint 모핑과 같은 방식).
- **링크**: 요소에 "슬라이드로 이동 / 웹 주소"를 걸면 발표 중 클릭해 이동합니다 (목차 → 각 장, 처음으로 버튼 …).
- **숨긴 슬라이드**: 썸네일 오른쪽 클릭 → 숨기기. 발표 때 건너뛰고, 번호를 눌러 직접 갈 수는 있습니다.
- **🎨 디자인**: 테마 16종 미리보기, 강조색·제목색 등 색 직접 지정, 제목/본문 글꼴, 장식(바·띠·모서리 원·테두리·모눈),
  **꼬리말**(슬라이드 번호 · 전체 장수 · 강의명/이름 문구, 표지 제외).
- **배경**: 테마 기본 / 단색 / 그라데이션 / 이미지(+어둡게).
- **정렬·그룹**: 여러 요소를 선택(Shift+클릭 또는 드래그)하면 정렬·등간격·같은 크기, **묶기(Ctrl+G)**, 모서리를 끌어 함께 크기 조절.
  `▦ 격자` 를 켜면 60px 격자에 맞춰 붙습니다.
- **☰ 개체 목록 (Alt+F10)**: 슬라이드의 요소를 앞뒤 순서대로 보여 주고, 끌어서 순서 바꾸기·숨기기·잠금·이름 붙이기.
- **찾기·바꾸기**: `Ctrl+F` / `Ctrl+H` — 모든 슬라이드의 글과 표에서 찾고 한 번에 바꿉니다.
- **복사**: 요소나 슬라이드를 `Ctrl+C` 하면 다른 교안(다른 탭)에도 `Ctrl+V` 로 붙여넣을 수 있습니다.
- **노트**: 슬라이드를 선택한 상태(요소 선택 없음)에서 오른쪽 패널의 발표자 노트를 적습니다.
- **저장**: 변경이 있으면 제목 옆에 점이 표시됩니다. 저장 전에도 임시본이 브라우저에 보관되어 `미리보기` 로 바로 볼 수 있습니다.

## 교안 파일 형식

`decks/<이름>.json`

```json
{
  "title": "교안 제목", "theme": "academic", "transition": "fade",
  "slides": [
    { "id": "...", "bg": null, "transition": "", "notes": "발표자 노트",
      "elements": [
        { "type": "text",  "role": "heading", "x": 120, "y": 90, "w": 1680, "h": 130, "html": "소제목", "style": {}, "step": 0 },
        { "type": "image", "x": 1000, "y": 260, "w": 800, "h": 660, "src": "assets/그림.png", "radius": 24, "shadow": true },
        { "type": "shape", "shape": "rect", "x": 120, "y": 690, "w": 220, "h": 12, "fill": "$accent" }
      ] }
  ]
}
```

- 요소 종류: `text`, `image`, `shape`, `table`(rows), `chart`(kind, data), `math`(tex), `embed`(url).
- 좌표계는 1920×1080 기준이며 화면 크기에 맞게 자동 축소/확대됩니다.
- 색에 `$accent`, `$accent2`, `$title`, `$fg`, `$muted`, `$surface`, `$bg` 를 쓰면 테마 색을 따라갑니다.
- 텍스트의 `role` (title, subtitle, heading, body, caption, quote, code, number) 에 따라 테마 기본 글꼴 크기·색이 정해지고, `style` 로 덮어씁니다.

## Git 으로 교안 모으기

```bash
git add decks assets
git commit -m "OO 과목 3주차 교안 추가"
git push
```

저장할 때마다 직전 버전이 `decks/<이름>.json.bak` 으로 남고(Git 제외), 삭제한 교안은 `decks/.trash/` 로 이동합니다.

## 세 가지 실행 방식

| 방식 | 저장 위치 | 용도 |
|---|---|---|
| `start.cmd` (로컬 서버) | `decks/`, `assets/` 폴더 파일 | 평소 작업. Git 으로 커밋·푸시 |
| GitHub Pages 주소 | GitHub 저장소 (토큰 연결 시) | 어디서나 발표, 급한 수정 |
| `index.html` 더블클릭 | 브라우저 localStorage | 임시 |

## 서버 없이 열면?

`index.html` 을 그대로 더블클릭해도 열리지만, 그때는 교안이 브라우저 안(localStorage)에만 저장됩니다.
폴더에 파일로 저장하려면 `start.cmd` 로 여세요.
