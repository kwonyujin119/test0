==== 0단계 · 준비 : 창고 만들기 도우미 ====
나는 GitHub를 처음 써. 코딩은 모르는 강사야.
브라우저에서 쓰는 나만의 발표 프로그램(PT 툴)을 만들려고 해.

지금부터 아래 일을 내가 따라 할 수 있게 화면 순서대로 하나씩 알려 줘.
1. GitHub에 새 저장소(창고) 만들기 — 이름은 my-pt, 공개(Public)로
2. 이 저장소를 AI(너)가 직접 고칠 수 있게 연결하는 방법
3. 나중에 이 저장소를 인터넷 주소로 공개(GitHub Pages)할 때 필요한 설정

[규칙]
- 한 번에 한 단계만 알려 주고, 내가 "다음"이라고 하면 다음 단계로
- 버튼 이름은 화면에 보이는 그대로 (영어면 영어 그대로) 적어 줘
- 내가 화면 캡처를 보내면, 그 화면에서 무엇을 누르면 되는지 짚어 줘
- 비밀번호·토큰 같은 비밀 값은 대화창에 붙여 넣으라고 하지 마

==== 1단계 · 형식 : 교안 파일 형식 정하기 ====
너는 웹 개발자야. 나는 코딩을 모르는 강사이고, 브라우저에서 쓰는 발표 프로그램을 만들려고 해.
먼저 "교안 파일 형식"만 정해 줘. 화면은 아직 만들지 마.

[형식 조건]
- 교안 1개 = JSON 파일 1개, decks/ 폴더에 저장 (예: decks/sample.json)
- 슬라이드 크기는 1920×1080 기준 좌표
- 구조: { title, slides: [ { bg, notes, elements: [...] } ] }
- 요소 종류: text(글), image(그림), shape(도형). 각 요소는 x, y, w, h, 그리고 step(몇 번째 클릭에 나타날지)
- 사람이 읽고 고칠 수 있게 단순하게. 나중에 AI가 이 파일을 직접 고칠 거야.

[참고] PowerPoint의 "슬라이드 / 개체 / 애니메이션 순서" 개념을 따르되, 파일은 JSON으로.

[완료 기준]
- 형식 설명 문서 docs/format.md 와 예시 교안 decks/sample.json (5장: 표지, 목차, 본문 2장, 마무리)
- 각 항목이 무슨 뜻인지 한국어로 설명

==== 2단계 · 발표기 : 발표 화면 만들기 ====
docs/format.md 형식의 교안을 발표하는 화면(present.html)을 만들어 줘.
외부 서버 없이 정적 파일만으로 동작해야 해 (GitHub Pages에 올릴 거야).

[기능]
- 주소 present.html?deck=sample 로 decks/sample.json 을 읽어 보여주기
- → · Space · 클릭: 다음 (step이 남아 있으면 요소를 하나씩 등장, 없으면 다음 장)
- ← : 이전 / Home·End: 처음·끝 / 숫자+Enter: 그 장으로
- F5 또는 F: 전체 화면 / B: 화면 검게 / Esc: 나가기
- 화면 크기가 달라도 16:9 비율을 유지하며 꽉 차게 (남는 곳은 검은 여백)
- 휴대폰에서는 좌우로 밀어서 넘기기
- S: 발표자 보기 새 창 (현재 장, 다음 장 미리보기, notes, 경과 시간)

[참고] reveal.js(revealjs.com)의 키보드 조작·전체 화면·발표자 보기 방식 — 동작만 참고하고 라이브러리는 쓰지 말 것 / PowerPoint 슬라이드 쇼 단축키(F5, B, 숫자+Enter)

[하지 말 것]
- 빌드 도구(npm, React 등) 쓰지 말 것. HTML·CSS·JS 파일만
- 교안 내용을 코드 안에 직접 적지 말 것 (반드시 JSON에서 읽기)

[완료 기준]
- 위 단축키를 하나씩 눌러 본 결과를 표로 보고
- 휴대폰 크기(390×844)와 PC 크기에서 화면을 캡처해서 보여주기

==== 3단계 · 공개 : 인터넷 주소로 공개하기 ====
지금 만든 발표 프로그램을 GitHub Pages로 공개해서 인터넷 주소를 알려 줘.

[조건]
- 내가 직접 눌러야 하는 설정이 있으면 화면 순서대로 알려 줘
- 공개가 끝나면 아래 두 주소를 알려 줘
  1) 사이트 첫 주소
  2) 예시 교안 발표 주소 (present.html?deck=sample)

[완료 기준]
- 두 주소가 실제로 열리는지 확인한 결과
- 고친 뒤 화면에 반영되기까지 몇 분 걸릴 수 있다는 것과, 안 바뀌면 새로고침하라는 안내

4단계 · 교안 목록

교안 목록(첫 화면) 만들기

언제: 교안이 2개 이상 생길 때

교안 목록 화면(index.html)을 만들어 줘. 이 사이트의 첫 화면이야.

[기능]
- decks/ 폴더의 교안들을 카드로 보여주기. 목록은 decks/index.json 한 파일로 관리 (교안을 추가하면 여기에 한 줄 추가)
- 카드: 첫 장 미리보기(축소 화면), 제목, 장 수, 고친 날짜
- 카드 누르면 present.html?deck=… 로 발표 / "편집" 단추는 나중에 만들 편집기로 연결 (지금은 숨김)
- 위에 검색칸 (제목으로 거르기), 폴더(분류)별 묶기
- 휴대폰에서는 카드 1열, PC에서는 3~4열

[참고] Google Slides 첫 화면(최근 프레젠테이션 카드 격자) / Notion 갤러리 보기 / 행정안전부 KRDS(디지털 정부 디자인 시스템)의 글자 크기·대비 기준

[완료 기준]
- 예시 교안 3개를 넣고 PC·휴대폰 화면을 캡처해 보여주기
- 검색칸에 글자를 넣었을 때 걸러지는지 확인 결과
5단계 · 첫 교안

AI로 첫 교안 만들기

언제: 목록까지 되면 — 그 뒤로는 수업마다

docs/format.md 형식으로 새 교안을 만들어 줘.

- 주제: (여기에 주제)
- 대상: (예: 신입 직원) · 시간: (예: 40분) · 장 수: 10장 안팎
- 구성: 표지 → 목차 → 본문 → 정리
- 한 장에 한 메시지. 글은 짧게, 설명은 발표자 노트(notes)에
- 글자는 24px 이상, 배경과 글자의 대비를 충분히

[완료 기준]
- decks/ 에 파일을 만들고 목록(decks/index.json)에도 추가
- 모든 장을 그림으로 뽑아서 글자가 넘치거나 잘린 곳이 없는지 확인한 결과
6단계 · 편집기

편집기 만들기 (세 번에 나눠서)

언제: 말로 고치는 게 불편해질 때 — 한 번에 하나씩

[6-1] editor.html 을 만들어 줘. 이번에는 "보기와 고르기"까지만.
- 왼쪽: 슬라이드 썸네일 목록 / 가운데: 현재 장 크게 / 오른쪽: 고른 요소의 속성(위치·크기·글자 크기·색)
- 요소를 클릭하면 테두리와 크기 조절 손잡이 8개 표시, 끌어서 이동, 손잡이로 크기 조절
- 아직 저장은 하지 말고, 화면에서만 바뀌게
[참고] Google Slides 편집 화면 배치 / PowerPoint 단축키: 방향키 이동, Shift+방향키 크게 이동, Ctrl+D 복제, Delete 삭제
[완료 기준] 요소 고르기·이동·크기 조절을 해 본 화면 캡처

---- (위가 끝나고 확인한 다음에) ----
[6-2] 이어서: 글 상자를 두 번 클릭하면 글을 직접 고치기, Ctrl+Z 되돌리기 / Ctrl+Y 다시, 슬라이드 추가·복제·삭제·순서 바꾸기(썸네일 끌기)
[완료 기준] 각 기능을 해 보고, 되돌리기로 원래대로 돌아오는지 확인 결과

---- (위가 끝나고 확인한 다음에) ----
[6-3] 이어서: 저장. 고친 교안을 GitHub 저장소의 decks/*.json 에 커밋하는 방식으로 (GitHub 토큰은 브라우저에만 저장, 코드에 넣지 말 것). 저장 전에는 "저장 안 됨" 표시, 창을 닫으려 하면 경고.
[완료 기준] 저장 → 새로고침 → 고친 내용이 남아 있는지 확인
